# Настройка LM Studio для AI Debate Arena

## Что добавлено

Теперь приложение поддерживает **динамический выбор моделей из LM Studio**:

1. **Автоматическое получение списка моделей** - при запуске приложение запрашивает у LM Studio все доступные модели
2. **Кнопка обновления** 🔄 - позволяет обновить список моделей без перезапуска приложения (полезно если вы загрузили новую модель в LM Studio)
3. **Индивидуальные настройки для агентов** - каждый агент может использовать свою модель из LM Studio

## Как настроить

### 1. Запустите LM Studio

- Откройте LM Studio
- Загрузите нужную модель (например, `llama-3.2-3b-instruct`, `qwen2.5-7b-instruct` и т.д.)
- Включите локальный сервер:
  - Перейдите на вкладку "Local Server" (↔️)
  - Убедитесь, что порт `1234`
  - Нажмите "Start Server"

### 2. Запустите AI Debate Arena

```bash
# Установите переменную окружения для использования LM Studio
export LLM_PROVIDER=lmstudio
# или для Windows:
# set LLM_PROVIDER=lmstudio

npm run dev
```

Или добавьте в `.env`:
```
LLM_PROVIDER=lmstudio
LMSTUDIO_BASE_URL=http://localhost:1234/v1
```

### 3. Выберите модель в интерфейсе

- Откройте приложение в браузере
- В секции "Модель (общая)" выберите нужную модель из выпадающего списка
- Если вы загрузили новую модель в LM Studio, нажмите кнопку 🔄 для обновления списка

## Продвинутые настройки

### Индивидуальные модели для агентов

1. Нажмите "▶ Настройки агентов (модели, температура)"
2. Для каждого агента можно выбрать:
   - **Провайдер**: Ollama, Groq или LM Studio
   - **Модель**: любая доступная модель
   - **Температура**: от 0 (точный) до 1.5 (креативный)

### Пример конфигурации

- **Philosopher**: `qwen2.5-7b-instruct` (температура 0.7) - для глубокого анализа
- **Skeptic**: `llama-3.2-3b-instruct` (температура 0.9) - для быстрой критики
- **Scientist**: `mistral-7b-instruct` (температура 0.8) - для фактов

## Troubleshooting

### "Не удалось получить список моделей"
- Убедитесь, что LM Studio запущен
- Проверьте, что сервер включён (кнопка "Start Server")
- Убедитесь, что порт 1234 не занят другим приложением

### "Модель не найдена"
- Проверьте, что модель загружена в LM Studio (зелёная иконка)
- Нажмите кнопку 🔄 для обновления списка

### "ECONNREFUSED"
- LM Studio не запущен или сервер выключен
- Брандмауэр блокирует соединение на порту 1234
