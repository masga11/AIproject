# Настройка Mistral AI

## Получение API ключа

1. Зарегистрируйтесь на [Mistral AI Platform](https://console.mistral.ai/)
2. Перейдите в раздел **API Keys**
3. Создайте новый ключ
4. Скопируйте и сохраните его

## Настройка проекта

### Вариант 1: Через .env файл

Создайте или отредактируйте файл `.env` в корне проекта:

```bash
LLM_PROVIDER=mistral
MISTRAL_API_KEY=ваш_ключ_mistral
```

### Вариант 2: Через переменные окружения

```bash
export LLM_PROVIDER=mistral
export MISTRAL_API_KEY=ваш_ключ_mistral
npm run dev
```

## Доступные модели

- **mistral-small-latest** - Быстрая модель для простых задач
- **mistral-medium-latest** - Сбалансированная модель (лучшее соотношение цена/качество)
- **mistral-large-latest** - Самая мощная модель для сложных задач
- **open-mistral-7b** - Лёгкая базовая модель
- **open-mixtral-8x7b** - Mixture of Experts для разнообразных задач

## Тарифы

Mistral AI предоставляет:
- Бесплатный тестовый период с ограниченным лимитом
- Pay-as-you-go тарифы (оплата за токены)

Актуальные цены смотрите на [официальном сайте](https://mistral.ai/technology/#pricing)

## Переключение между провайдерами

Вы можете переключаться между провайдерами:

```bash
# Ollama (локально, бесплатно)
LLM_PROVIDER=ollama

# Groq (облако, быстро)
LLM_PROVIDER=groq
GROQ_API_KEY=ваш_ключ_groq

# Mistral AI (облако, качественно)
LLM_PROVIDER=mistral
MISTRAL_API_KEY=ваш_ключ_mistral

# LM Studio (локально, свои модели)
LLM_PROVIDER=lmstudio
```

## Индивидуальные настройки агентов

В расширенных настройках дебатов можно задать для каждого агента:
- Отдельного провайдера (Ollama, Groq, Mistral, LM Studio)
- Отдельную модель
- Температуру генерации

Это позволяет сравнивать разные модели в одних дебатах!

## Возможные ошибки

### "Не задан MISTRAL_API_KEY"
Добавьте ключ в `.env` или установите переменную окружения `MISTRAL_API_KEY`.

### "Неверный API ключ Mistral"
Проверьте правильность ключа в `.env`. Убедитесь, что нет лишних пробелов.

### "Лимит запросов исчерпан"
Mistral AI имеет ограничения на количество запросов. Подождите немного или проверьте свой тарифный план.
